1. Makmal Bit Interaktif

Bit Network (1) Bit Host (0)

2. Cara Mudah Mengingat

IPv4 ada 32 bit. Untuk /29, bit Host = 32 − 29 = 3, maka jumlah IP = 2³ = 8 dan usable host = 8 − 2 = 6.

Subnet mask /29: 24 bit pertama memberi 255.255.255, manakala oktet terakhir 11111000 = 128 + 64 + 32 + 16 + 8 = 248. Jadi 255.255.255.248.
