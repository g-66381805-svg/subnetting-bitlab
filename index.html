DKB2232 • IPv4 Addressing

🧠 Subnetting BitLab

Inovasi pembelajaran interaktif: fahami bit, kira IP, jawab cabaran dan jana sijil pencapaian.

Bahasa Melayu • Percuma • Boleh digunakan tanpa Internet selepas fail dimuat turun

1. Makmal Bit Interaktif

Bit Network (1) Bit Host (0)

2. Cara Mudah Mengingat

IPv4 ada 32 bit. Untuk /29, bit Host = 32 − 29 = 3, maka jumlah IP = 2³ = 8 dan usable host = 8 − 2 = 6.

Subnet mask /29: 24 bit pertama memberi 255.255.255, manakala oktet terakhir 11111000 = 128 + 64 + 32 + 16 + 8 = 248. Jadi 255.255.255.248.

3. Cabaran Subnetting 🎯

Soalan pelbagai: subnet mask, jumlah IP, usable host, bit Host, network, broadcast, host pertama/terakhir dan block size. Setiap sesi menjana soalan rawak.
